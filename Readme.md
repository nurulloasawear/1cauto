1C Автоматизация Скрипти - README
🚀 Лойиха ҳақида
Бу лойиха Excel файлидаги маълумотларни 1С дастурига автомат равишда киритиш учун яратилган Python скрипти. Скрипт экрандаги расмларни таниб, тугмаларга босиб, маълумотларни киритиш жараёнини автоматлаштиради.

📋 Фойдаланилган технологиялар
Python 3.8+

pyautogui - экрандаги элементларни таниш ва ишлатиш

pandas - Excel файлларни ўқиш ва қайта ишлаш

openpyxl - Excel файллар билан ишлаш

datetime - вақт ва сана маълумотларини ишлаш

⚙️ Урнатиш
1. Зарурий шартлар
Python 3.8 ёки юқори версия

1С дастури (тизимда ўрнатилган бўлиши керак)

Windows операцион тизими (Linux/Mac учун ўзгартиришлар талаб қилинади)

2. Библиотекаларни ўрнатиш
bash
pip install pyautogui pandas openpyxl pillow
Ёки requirements.txt файли орқали:

bash
pip install -r requirements.txt
🔧 Созламалар
1. Расм файлларини тайёрлаш
1С дастуридаги тугма ва майдонларнинг скриншотларини олинг ва қуйидаги манзилларга сақланг:

Тугмалар: C:\code\1c\buttons\

Майдонлар: C:\code\1c\input\

2. Excel файлини тузиш
Excel файли қуйидаги устунларни ўз ичига олиши керак:

дата - сана маълумотлари

Номер заказа - заказ рақами

sku - товар коди

цена продажи за одну штуку - бир товар нархи

количество - микдори

общая сумма заказа - жами сумма

Транзакции по заказам и товарам статус - статус

Муҳим: Файл 3-қатордан бошланиши керак (2 та сарлавҳа қатори бўлиши керак)

3. Скриптни созлаш
main.py файлидаги манзилларни ўз тизимингизга мослаштиринг:

python
# 1C тугмалари учун
```
start_button_image_path = r"СИЗНИ МАНЗИЛИНГИЗ\start.jpg"
```
# Excel файли учун
```
excel_path = r"СИЗНИ МАНЗИЛИНГИЗ\файл.xlsx"
```
🎯 Ишлатиш
1. Дастурни ишга туширишдан олдин:
1С дастурини очинг ва керали экранга ўтинг

Excel файли мавжудлигини текширинг

Расм файлларининг манзиллари тўғри эканлигини текширинг

2. Скриптни ишга тушириш:
bash
python main.py
3. Жараённи кузатиш:
Скрипт ишлаганида экранда қайси амаллар бажарилаётганини кўрсатиб боради:

Қайси тугмалар босилмоқда

Қайси маълумотлар киритилмоқда

Қанча қатор ишланган

📊 Ишлаш тартиби
Асосий қадамлар:
Дастурни ишга тушириш - 3 сония куттириш

Excel файлини ўқиш - маълумотларни қайта ишлаш

1C экранини аниқлаш - тугмаларни топиш

Маълумотларни киритиш - ҳар бир қатор учун:

Старт тугмасини босинш

Сана ва вақтни киритиш

Заказ рақамини киритиш

Подбор тугмасини босинш

SKU кодни киритиш

Нархни киритиш (иккинчи тугма учун)

OK тугмасини босинш
